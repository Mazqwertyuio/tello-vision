# Tello Vision: Пряме уникнення перешкод по карті глибини та слідування за силуетом людини

Проста, надійна та реактивна система автономного керування для **DJI Tello**:
1. **Карта глибини (Depth Anything V2 на CUDA)** для запобігання зіткненням.
2. **Розпізнавання силуету людини (YOLOv8n на CUDA)** для супроводу.

---

## 🎯 2 Режими роботи

### 1. Дослідження приміщення з уникненням зіткнень (`EXPLORE` [E])
- Карта глибини розбивається на 3 сектори: **Ліво (L) | Центр (C) | Право (R)**.
- **Центр вільний** -> дрон летить уперед (`forward = 20`).
- **Попереду перешкода** -> дрон припиняє рух уперед (`forward = 0`) і плавно розвертається в той бік, де глибше (менше перешкод), поки центр не звільниться.
- **Рух назад повністю заборонено** (задня півсфера сліпа).

### 2. Слідування за силуетом людини (`FOLLOW` [F])
- Використовує нейромережу **YOLOv8n** для виявлення силуету людини (в повний зріст або по пояс).
- Утримує людину по центру кадру (поворот `yaw` та висота `ud`).
- Летить уперед до людини, якщо людина далеко.
- **Захист по карті глибини**: якщо між дроном та людиною виникає стіна або перешкода — рух уперед **блокується** (`forward = 0`).

## 🕹 Керування

| Клавіша / Кнопка | Дія |
|---|---|
| **[T]** / `TAKEOFF` | Зліт |
| **[L]** / `Space` / `LAND` | Посадка |
| **[E]** / `EXPLORE [E]` | **Режим 1: Дослідження приміщення (обхід перешкод по глибині)** |
| **[F]** / `FOLLOW [F]` | **Режим 2: Слідування за силуетом людини** |
| **W, A, S, D** | Ручний політ із захистом від зіткнень |
| **Esc / Q** | Аварійна зупинка та вихід |
